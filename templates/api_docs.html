CryptoRadar.

API Documentation

Free open API. No authentication.

GET /api/rankings

All 100 ranked tokens with scores, prices, sparklines.

curl https://cryptoradar.dev/api/rankings

GET /api/token/{id}/history

Token score history. id = CoinGecko ID (e.g. bitcoin).

curl https://cryptoradar.dev/api/token/bitcoin/history

GET /api/token/{id}/chart?days=7

Historical prices. days=1, 7, or 30.

curl 'https://cryptoradar.dev/api/token/bitcoin/chart?days=30'

GET /api/last-refresh

Last refresh timestamp.

curl https://cryptoradar.dev/api/last-refresh

Rate Limits

No auth required. Please limit to 1 req/s. Data refreshed hourly from CoinGecko.
